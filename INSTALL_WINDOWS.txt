LocalVoiceAI iOS v3.2 Voice — Windows
===================================

1) ZIP'i aç.
2) İçindeki .github, patches, README.md, .gitignore ve INSTALL_WINDOWS.txt dosyalarını
   mevcut local-qwen-ios repo klasörünün üzerine kopyala.
3) Git Bash'i repo kökünde aç:

   git add .
   git commit -m "LocalVoiceAI v3.2 voice"
   git push

4) GitHub -> repo -> Actions -> "Build LocalVoiceAI iOS v3.2 Voice".
5) Artifact "LocalVoiceAI-v3.2-Voice-unsigned-IPA" dosyasını indir.
6) İçinden LocalVoiceAI-v3.2-Voice-unsigned.ipa'yı çıkar.
7) Sideloadly + Remote Anisette ile iPhone'a kur.

Telefon:
- Qwen: Qwen3-1.7B-Q4_K_M.gguf
- Whisper: ggml-base-q5_1.bin (multilingual)
- Whisper switch: aç
- Düşük bellek modu: iPhone 13 için açık bırak
- Mikrofona bir kez bas: kayıt başlar
- Tekrar bas: kayıt biter -> Whisper -> Qwen -> TTS

Not: Qwen ve Whisper model dosyaları IPA'nın içinde değildir. Aynı uygulamanın Documents alanına
atılır; model değiştirmek için yeniden IPA sign etmen gerekmez.
